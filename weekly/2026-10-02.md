## 详细介绍

### 1. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)

Cloudflare 开源的多阶段安全审计编码代理技能，能够执行全面的代码安全检查，输出机器可读的独立验证结果。该技能与 CI/CD 流程深度集成，支持漏洞扫描、安全合规检查和修复建议，覆盖 Web 安全、API 安全、云原生安全等多个维度。借助 Cloudflare 的全球基础设施，可实现大规模自动化安全审计，帮助开发团队在代码提交阶段即发现并修复安全问题。

**GitHub 链接**：https://github.com/cloudflare/security-audit-skill

### 2. [stablyai/orca](https://github.com/stablyai/orca)

Orca 是一款专为多代理并行工作流设计的 AI 开发环境（ADE），允许用户同时运行多个编码代理并协调管理。它支持在桌面端、移动端和远程运行时环境中运行，用户可接入自己的订阅服务。在复杂项目中，Orca 能够将任务分解并分配给多个并行代理，显著提升大型代码库的处理效率，是当前多代理协作领域备受关注的开源方案。

**GitHub 链接**：https://github.com/stablyai/orca

### 3. [affaan-m/ECC](https://github.com/affaan-m/ECC)

ECC（Extended Claude Capability）是一个 Agent 性能优化系统，为 Claude Code、Codex、Opencode、Cursor 等主流 AI 编码工具提供技能、本能、记忆、安全和研究驱动开发能力。该项目包含丰富的内置技能库、智能决策本能机制、安全防护层和上下文记忆管理，是当前最全面的 Agent 性能优化开源框架之一，GitHub 总 Stars 已突破 26 万。

**GitHub 链接**：https://github.com/affaan-m/ECC

### 4. [alibaba/open-code-review](https://github.com/alibaba/open-code-review)

阿里巴巴开源的混合架构代码审查工具，将确定性流水线与 LLM Agent 深度融合，在阿里内部生产环境经过大规模验证。该工具能够精确定位代码行级问题，内置多语言规则集，覆盖空指针异常、线程安全、XSS、SQL 注入等常见漏洞类型，同时兼容 OpenAI 和 Anthropic 的 API 接口，支持灵活部署。

**GitHub 链接**：https://github.com/alibaba/open-code-review

### 5. [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight)

Hindsight 是一款具有学习能力的 Agent 记忆系统，能够帮助 AI 代理在多轮对话和长时任务中持续积累和利用上下文知识。与传统的静态记忆不同，Hindsight 能够从历史交互中提取关键模式，主动关联相关信息，显著提升 Agent 在复杂任务中的连贯性和准确性，是构建长期记忆 Agent 的重要基础设施。

**GitHub 链接**：https://github.com/vectorize-io/hindsight
