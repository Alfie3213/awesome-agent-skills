## 详细介绍

### 1. [obra/superpowers](https://github.com/obra/superpowers)

Superpowers 是一个 Agentic 技能框架与软件工程方法论项目，旨在让 AI Agent 具备真正的系统性开发能力。它不仅仅是一个工具库，更是一套完整的 Agent 开发范式，强调技能分解、上下文管理和任务规划。不同于传统的单 Agent 工具，Superpowers 鼓励将复杂任务拆解为可组合的技能单元，通过层次化的技能体系实现可靠的软件工程输出。GitHub Stars 已突破 29 万，是当前最具影响力的 Agent 工程化实践之一。

**GitHub 链接**：https://github.com/obra/superpowers

---

### 2. [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)

Hermes Agent 是 NousResearch 团队推出的渐进式成长型 AI Agent 框架，核心理念是让 AI Agent 能够像人类一样在多轮交互中持续学习和适应。与传统静态 Agent 不同，Hermes 具备动态知识更新能力，能够从对话历史中提取模式、修正错误并积累经验。项目采用模块化架构，支持多种底层 LLM，包括 Claude、GPT 系列和开源模型，为开发者提供了灵活的定制空间，是当前成长型 Agent 领域的标杆项目。

**GitHub 链接**：https://github.com/NousResearch/hermes-agent

---

### 3. [anthropics/skills](https://github.com/anthropics/skills)

Anthropic 官方开源的 Agent Skills 公共仓库，汇集了 Claude Code 和 Claude Agent 的各类技能定义与最佳实践。这些技能涵盖代码审查、bug 修复、文档生成、测试编写、数据分析等多个开发场景，全部经过 Anthropic 内部验证。每个技能都包含详细的 prompt 模板、执行约束和输出格式规范，开发者可以直接复用或在此基础上定制自己的 Agent 工作流，是深入理解 Claude Agent 能力边界的重要参考。

**GitHub 链接**：https://github.com/anthropics/skills

### 4. [openclaw/openclaw](https://github.com/openclaw/openclaw)

OpenClaw 是一个通用 AI 助手框架，主打"真正做事情"的理念，支持在任意操作系统和平台上运行。它提供了完整的工具调用体系、任务编排能力和记忆管理机制，让 AI Agent 不仅能回答问题，更能实际执行文件系统操作、浏览器自动化、代码执行等真实任务。OpenClaw 的设计哲学强调可控性和可观测性，每个 Agent 操作都有清晰的日志和审计轨迹，适合需要深度 AI 集成的生产环境。

**GitHub 链接**：https://github.com/openclaw/openclaw

---

### 5. [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)

Firecrawl 是专为 AI Agent 设计的大规模网络数据采集引擎，能够将任意网站转化为结构化的 AI 可用数据。它不仅处理静态页面，还能执行 JavaScript 渲染、处理 SPA 应用、绕过反爬机制，并输出干净的 Markdown 或结构化数据。Firecrawl 提供了完善的 API 和 SDK，支持批量采集、去重、质量过滤等功能，是构建 RAG 系统、训练数据集或为 Agent 提供实时网络知识的关键基础设施。本周增长强劲，受益于 AI 数据需求的爆发。

**GitHub 链接**：https://github.com/firecrawl/firecrawl

### 6. [ollama/ollama](https://github.com/ollama/ollama)

Ollama 是最受欢迎的本地大模型运行平台，让开发者能够零配置地在本地运行包括 Qwen、DeepSeek、GLM、MiniMax、Gemma、Llama 在内的数十种开源大语言模型。它提供了统一的 API 接口，本地模型和云端模型可以无缝切换，极大降低了本地 AI 开发的门槛。Ollama 还支持模型的量化、微调和自定义导入，是个人开发者和中小企业构建私有 AI 能力的重要工具，也是 Agent 本地化部署的首选方案。

**GitHub 链接**：https://github.com/ollama/ollama

**GitHub 链接**：https://github.com/multica-ai/andrej-karpathy-skills

### 8. [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)

Ponytail 提出了一个有趣的编程哲学：**最好的代码是你根本没写的代码**。它是一组 Agent 技能集，旨在让 AI Agent 像最懒但最有经验的高级开发者一样思考——优先复用、追求简洁、警惕过度工程。Ponytail 技能涵盖代码审查的"删除优先"策略、依赖管理原则、API 简化建议等，帮助团队避免被 AI 生成的过多代码所拖累，在 AI 辅助开发时代保持代码库的长期健康。

**GitHub 链接**：https://github.com/DietrichGebert/ponytail

### 9. [langchain-ai/langchain](https://github.com/langchain-ai/langchain)

LangChain 是大模型应用开发的基础框架，提供了从 Prompt 管理、Chain 编排、Agent 构建到 Memory 系统、RAG 检索、工具调用的完整工具链。最新版本 LangChain 3.x 将自己定位为"Agent 工程平台"，强化了多 Agent 协作、流式输出、部署观测等企业级能力。LangChain 拥有庞大的生态系统和活跃的社区，配套文档和教程丰富，是构建复杂 AI 应用时不可或缺的底层框架。

**GitHub 链接**：https://github.com/langchain-ai/langchain

### 10. [microsoft/mcp-for-beginners](https://github.com/microsoft/mcp-for-beginners)

微软推出的 MCP（Model Context Protocol）官方入门课程，以 Jupyter Notebook 的形式手把手教学。MCP 是 Anthropic 提出的模型上下文协议，旨在标准化 AI 模型与应用之间的交互方式，让 Agent 能够可靠地调用外部工具和数据源。本课程覆盖 MCP 的核心概念、协议规范、服务器实现和实际集成案例，配有完整的代码示例，适合希望深入理解 Agent 工具调用机制或构建自己 MCP 服务的开发者。

**GitHub 链接**：https://github.com/microsoft/mcp-for-beginners

**本周总体态势**：AI/Agent 领域继续保持高速发展，技能框架、数据基础设施、本地化推理三大方向同步升温，2026年第四季度 AI Agent 正从"能用"迈向"好用"的工程化深水区。
