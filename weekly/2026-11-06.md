## 详细介绍

### 1. [t3code](https://github.com/pingdotgg/t3code)
T3 Code 是一个「Agent Harness 控制面板」，允许你通过 iOS、Android、Web 以及 Electron 桌面端远程操控本机运行的各类编码 Agent。它直接复用你已有的 Claude Code、Codex、Cursor、Grok Build、OpenCode、Google Antigravity 订阅，无需另付模型费用。支持一键安装、远程就绪与完全开源，团队强调性能与可分叉性。本周新增超过 1.6 万星，是当周 AI 编程工具链最热项目。

**GitHub链接**：https://github.com/pingdotgg/t3code

### 2. [claude-mem](https://github.com/thedotmack/claude-mem)
claude-mem 解决 Agent「失忆」痛点：在会话期间捕获 Agent 的全部操作，用 AI 压缩成结构化记忆，并在后续会话中把相关上下文自动注入回去。它兼容 Claude Code、OpenClaw、Codex、Gemini、Copilot、OpenCode 等主流 Agent，是真正意义上跨工具的通用记忆层，本周热度位列前二。

**GitHub链接**：https://github.com/thedotmack/claude-mem

### 3. [impeccable](https://github.com/pbakaus/impeccable)
impeccable 提出了「编码 Agent 的设计词汇表」这一概念：教 Agent 用打磨过的表达方式做设计，用批判与审计视角做代码评审，并在生成阶段就拦截 AI 味的粗糙产物（AI slop）。它以 Rust 实现、强调审查与品味，适合希望在编码环节就保证界面质感与一致性的团队。

**GitHub链接**：https://github.com/pbakaus/impeccable

### 4. [hallmark](https://github.com/Nutlope/hallmark)
hallmark 是一个反 AI 味（anti-AI-slop）的设计 Skill，可直接装进 Claude Code、Cursor 与 Codex。它把「避免模板化、无个性、像 AI 生成」的审美规则打包成可复用指令，让 Agent 产出的页面拥有品牌感与辨识度。本周 CSS 生态中唯一上榜的设计类 Skill，增长极为迅猛。

**GitHub链接**：https://github.com/Nutlope/hallmark

### 5. [DeepTutor](https://github.com/HKUDS/DeepTutor)
DeepTutor 定位为「终身个性化辅导系统」，不是一次性问答，而是持续建模学习者水平、知识薄弱点与学习节奏，再据此生成定制化的讲解与练习。项目以 Python 为主，配套在线体验站点，来自 HKUDS 团队，兼具研究价值与教育场景想象力。

**GitHub链接**：https://github.com/HKUDS/DeepTutor

### 6. [OpenMausBot](https://github.com/milind-soni/OpenMausBot)
OpenMausBot 是一个开源的 Grok Bot 替代方案，核心特色是内置一个可供机器人实际操作的虚拟机，让 Agent 具备真实环境中的执行能力，而不只是文本生成。它以 TypeScript 编写，可自托管，面向需要「能动手」的自动化场景。

**GitHub链接**：https://github.com/milind-soni/OpenMausBot

### 7. [taste-skill](https://github.com/Leonxlnx/taste-skill)
taste-skill 的目标是让编码 Agent「有品味」：引入艺术指导（art direction）、参考图机制，以及用浏览器真实预览页面自检，而不是产出千篇一律的通用 AI 页面。它把设计经验与视觉验证闭环结合起来，本周新增超过 5.4k 星。

**GitHub链接**：https://github.com/Leonxlnx/taste-skill

### 8. [superpowers](https://github.com/obra/superpowers)
superpowers 是一套 Agent 技能框架，配套完整的软件开发方法论：把最佳实践拆解成可被 Agent 加载与执行的技能包，用流程约束让编码 Agent 的行为更可预测、更工程化。它是全站星标数最高的 Agent 项目之一，说明「技能 + 方法论」正在成为 Agent 工程的标准范式。

**GitHub链接**：https://github.com/obra/superpowers

### 9. [OpenMontage](https://github.com/calesthio/OpenMontage)
OpenMontage 号称全球首个开源智能体视频生产系统，内置 12 条生产流水线、100 多个工具以及数百个 Agent 技能与生产知识。它把脚本、配音、剪辑、渲染等环节标准化为 Agent 可编排的流程，是「Agent 深入重创意行业」的代表性项目。

**GitHub链接**：https://github.com/calesthio/OpenMontage

### 10. [andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)
该项目把 Andrej Karpathy 关于 LLM 编码陷阱的观察，浓缩成一份 CLAUDE.md 文件，用来改善 Claude Code 的行为表现。形式极简——一份文档即可——但示范了「用极小上下文撬动显著行为改进」的价值，星标数已超 23 万。

**GitHub链接**：https://github.com/multica-ai/andrej-karpathy-skills

## 趋势洞察

1. **Skills 成为本周绝对主角**：本周榜前十里，anthropics/skills、obra/superpowers、jakubkrehel/skills 以及 hallmark、taste-skill、impeccable 等设计类 Skill 集体霸榜，Skills 从概念验证走向生态化竞争，官方仓库与社区框架双线推进。

2. **Agent 控制面与记忆层成刚需**：t3code（跨端远程控制 Agent）与 claude-mem（跨会话持久记忆）同时冲进前三，说明开发者当前最痛的两件事是「随时掌控 Agent」和「让 Agent 不失忆」，基础设施层的机会窗口正在打开。

3. **反 AI 味成为新的设计战场**：impeccable、taste-skill、hallmark 三者思路一致——用设计与审美规则约束模型输出，把「AI 味」当作可工程化治理的质量缺陷，而非玄学问题。

4. **Agent 走出代码，进入教育与视频生产**：DeepTutor 面向终身个性化学习，OpenMontage 面向视频生产流水线，OpenMausBot 则让 Agent 拥有可操作的虚拟机，Agent 的应用边界正从 IDE 迅速外扩到重内容行业。

5. **轻量提示同样有效**：andrej-karpathy-skills 仅凭一份 CLAUDE.md 就收获 23 万星，提醒我们上下文工程的价值往往来自极简而精准的经验注入，而非庞大的框架堆砌。
