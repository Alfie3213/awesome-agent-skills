## 详细介绍

### 1. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)

Cloudflare 官方开源的编码 Agent 安全审计技能，把 Agent 变成可复用的安全审计器。它按六个阶段推进：架构侦察生成覆盖清单、覆盖率驱动的漏洞猎手并行狩猎、候选漏洞交由全新验证者尝试推翻、输出结构化 findings.json、独立记录复核，再生成中立目标导向的报告。多轮运行可累加，不会重复劳动。既是研究团队搭建漏洞挖掘流水线的起点，也是企业安全团队落地 AI 审计的理想模板。

**GitHub链接**：https://github.com/cloudflare/security-audit-skill

### 2. [claude-seo](https://github.com/AgriciDaniel/claude-seo)

面向 Claude Code 的免费开源 SEO 审计插件，包含 26 个子技能与 19 个专职 Agent，覆盖技术 SEO、E-E-A-T、Schema.org、GEO/AEO 面向 AI 搜索引擎的优化、Agent 就绪度（Lighthouse Agentic Browsing、WebMCP、llms.txt）、外链、本地 SEO、电商与国际 SEO、Google API 集成以及 PDF/Excel 报告输出，并提供 9 个可选的实时数据扩展模块。目标很明确：既在 Google 排更前，也被 ChatGPT、Perplexity、Gemini、Claude 引用。

**GitHub链接**：https://github.com/AgriciDaniel/claude-seo

### 3. [impeccable](https://github.com/pbakaus/impeccable)

这是给编程 Agent 的「设计词汇表」。它用 polish、bolder 指挥 Agent 做出更有质感的设计，用 critique、audit 复审现有界面，并在代码上线前拦截千篇一律的 AI 味套路——紫蓝渐变、卡片套卡片、灰字压彩底、图标方块堆在标题上方。安装只需一条 `npx impeccable install`，支持 Claude Code、Cursor、Codex、Copilot、Devin、Gemini CLI、OpenCode 等二十余种编程助手，把通用模型变成有审美判断力的前端搭档。

**GitHub链接**：https://github.com/pbakaus/impeccable

### 4. [superpowers](https://github.com/obra/superpowers)

一套完整的、面向编码 Agent 的软件开发方法论，由一组可组合的技能（skills）与初始指令构成，确保 Agent 真正按流程干活而非随手发挥。它强调从头脑风暴、计划、测试驱动到子 Agent 分工的系统化链路，并提供面向 Claude Code、Codex、Cursor、Copilot CLI、Gemini CLI、OpenCode、Qwen Code、Hermes 等工具的安装指引。项目累计超过 30 万星、2.7 万 fork，是当前最被广泛采用的 Agent 方法论框架。

**GitHub链接**：https://github.com/obra/superpowers

### 5. [TradingAgents](https://github.com/TauricResearch/TradingAgents)

Tauric Research 出品的多 Agent LLM 金融交易框架，对应 arXiv 论文 2412.20138。系统让基本面分析师、情感分析师、看空研究员、看多研究员、研究经理、风险管理员和交易员等角色协作辩论，模拟真实投研团队的分工协作与观点碰撞。项目提供完整的多语言文档与社区 Discord，是学术 Agent 走向垂直领域落地最具代表性的案例之一，也是多 Agent 编排范式的经典参考实现。

**GitHub链接**：https://github.com/TauricResearch/TradingAgents

### 6. [andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)

一个 CLAUDE.md 文件就能改善 Claude Code 行为，源自 Andrej Karpathy 对 LLM 编码陷阱的观察总结。它针对四类顽疾给出对应原则：模型替用户做错误假设并盲目顺从、不管理自身困惑、不主动求澄清、不暴露矛盾与权衡、不该push back时也不push back；以及过度设计、抽象臃肿、不清理死代码、千行代码干一百行的事、顺手改动不理解的代码与注释等副作用。轻量但直击 AI 编码的核心痛点。

**GitHub链接**：https://github.com/multica-ai/andrej-karpathy-skills

## 趋势洞察

本周榜单最清晰地传递出一个信号：**Agent Skills 已经从「概念验证」走向「生态竞争」**。13 个上榜仓库中有 9 个是 skill / harness / plugin 类项目，直接以 skill 为命名或核心卖点的就占了 7 席，Skill 已经取代 Prompt 成为新的封装单位。

**一、安全与工程方法论成为新的高地。** 榜首的 cloudflare/security-audit-skill 一周暴涨 14,320 星，占据本周总增量的绝对头部。它代表一类重要转向：不再让 Agent「写更多代码」，而是让 Agent「验证代码」。六阶段流程、独立验证者、覆盖率账本、可机读 findings——这些机制背后是一整套软件工程严谨性被写进 skill 的尝试。同样，superpowers 的开发方法论、ECC 的 agent harness 性能优化体系都在补齐 Agent 缺失的工程纪律。

**二、「反 AI 味」形成独立赛道。** impeccable（+9,713）、taste-skill（+4,359）、jakubkrehel/skills 三者指向同一诉求：模型能生成可用界面，但生成不了有品位的界面。审美、参考图、浏览器校验、批判审查正在被产品化为可安装的技能包。这类项目上月还籍籍无名，本周集体爆发，说明「让 Agent 干活」的需求已饱和，需求正在向「让 Agent 干得体面」迁移。

**三、垂直领域 Agent 从框架走向岗位插件。** TradingAgents 展示多角色辩论式的领域仿真，claude-seo 用 26 子技能 + 19 专职 Agent 覆盖单一职能，Anthropic 官方的 knowledge-work-plugins 则把岗位插件化、标准化的路径摆到了台面上。三者共同说明：Agent 的下一个战场不是「通用助手」，而是「某个岗位干得比人好」。

**四、远程控制与多端协同成为基础设施需求。** t3code 一周新增 2,142 星，反映出 Agent 运行在本地、但人不在本地的新常态。控制面（control surface）正在成为独立的产品类别，和 MCP、Skills 一样，逐渐成为 Agent 生态的标准零件。

**五、生态整合的旗帜已经竖起。** Anthropic 官方开仓、Cloudflare 官方开源、Theo（t3code）等头部玩家入场，意味着 Skills 正从个人玩家的玩具变成可被信任、可被审计、可被企业采购的工程资产。与此同时，obra/superpowers 的 30 万星与 affaan-m/ECC 的 29 万星也提醒我们，通用框架的护城河依然很高——「造框架」与「造技能」正在分化为两条并行的赛道。
