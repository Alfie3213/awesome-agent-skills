## 详细介绍

### 1. [mattpocock/skills](https://github.com/mattpocock/skills)
Matt Pocock（TypeScript 社区知名教育者）把自己日常使用的 `.agents` 目录完整开源，是目前仓库体量最大的个人 Skills 集合。内容覆盖工程日常的高频动作：从代码审查、类型迁移、测试补全到发布流程与文档撰写，每一条都以可直接复制粘贴的提示词与配置形式给出，不依赖任何黑盒封装。亮点在于"真刀真枪"——每条 Skill 都来自作者本人的真实工作流，可读性强、迁移成本低，是学习如何写高质量 Skill 的最佳范本之一，也适合直接当团队内部 Agent 的起步基线。

**GitHub链接**：https://github.com/mattpocock/skills

### 2. [anthropics/skills](https://github.com/anthropics/skills)
Anthropic 官方维护的 Agent Skills 公共仓库，是整个 Skills 生态的事实标准来源。仓库以文档 + 可执行脚本的形式，示范了 Skill 的标准目录结构、渐进式加载策略以及与 Claude Code 的配合方式，涵盖文档处理、PDF/表格解析、幻灯片生成等官方范式。它的意义在于"定标准"：任何第三方 Skill 若想被 Claude Code、Agent SDK 生态直接复用，遵循这里的约定几乎是必经之路。想快速理解 Skill 到底该怎么写、怎么组织、怎么被调用，这份仓库是最高效的入口。

**GitHub链接**：https://github.com/anthropics/skills

### 3. [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)
Google Chrome 团队的 Addy Osmani 维护的生产级 AI 编码 Agent 技能集，强调"能真正上线"而非"演示效果"。技能覆盖性能优化、可访问性审查、SEO 检查、依赖升级、测试覆盖率补强等真实工程环节，每条都附带明确的验收标准与失败处理逻辑。其特点是站在浏览器与 Web 性能视角，把资深工程师的隐性经验固化成 Agent 可执行的流程，适合中大型前端团队直接引入到日常编码助手的配置中。

**GitHub链接**：https://github.com/addyosmani/agent-skills

### 4. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)
Cloudflare 官方开源的编码 Agent 安全审计 Skill，主打"多阶段审计 + 独立验证 + 机器可读结论"三位一体。它把一次安全审计拆成多个独立阶段，每阶段的发现结果都带有可复现的验证方式，最终输出结构化的机器可读 findings，便于接入 CI/CD 自动拦截或人工复核。本周新增星标数超过 1 万，是周榜中涨势最猛的仓库之一，反映出团队对 Agent 承担安全职责的强烈兴趣。

**GitHub链接**：https://github.com/cloudflare/security-audit-skill

### 5. [NVIDIA/auto-ontology](https://github.com/NVIDIA/auto-ontology)
NVIDIA 推出的 Python 框架，用于在数据之上自动构建基于语义图谱的推理层，目标是让查询生成从"模型自由发挥"变成"确定性可复现"。它通过本体（ontology）建模把业务概念、实体关系与约束显式化，再由图结构推导查询与答案，从而显著降低 LLM 在数据问答场景中的幻觉率。支持增量更新与多数据源接入，适合作为 RAG 与 Agent 数据层的新一代基础设施，目前 Star 数虽小但本周增速亮眼。

**GitHub链接**：https://github.com/NVIDIA/auto-ontology

### 6. [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser)
Vercel Labs 用 Rust 重写的浏览器自动化命令行工具，专为 AI Agent 场景设计。相比基于 CDP 的 Node 方案，它启动更快、内存更省，并提供快照（snapshot）式的 DOM 结构输出，让模型能用精简的文本结构而不是原始 HTML 来定位元素。命令覆盖导航、点击、输入、截图与表单填写，是目前 Agent 联网能力最常用的开源基建之一，也是许多 MCP 浏览器服务的底层替代方案。

**GitHub链接**：https://github.com/vercel-labs/agent-browser

### 7. [vercel-labs/agent-desktop](https://github.com/vercel-labs/agent-desktop)
同样出自 Vercel Labs 的 computer use CLI，把"操作电脑"这件事变成 Agent 可调用的命令行能力。它让模型可以启动应用、点击界面、输入文本、读取屏幕内容，从而突破纯 API 的边界去处理那些没有接口的系统。它与 agent-browser 形成互补：一个解决网页，一个解决桌面 GUI。本周新增六千余星，是 agent-browser 之外 Vercel 在 Agent 工具链上的又一大动作。

**GitHub链接**：https://github.com/vercel-labs/agent-desktop

### 8. [anthropics/claude-quickstarts](https://github.com/anthropics/claude-quickstarts)
Anthropic 官方整理的 Claude API 快速上手项目合集，目标是让开发者几分钟内跑通一个可部署的完整应用。示例涵盖对话接口、流式输出、工具调用（tool use）、检索增强、文件处理与 MCP 接入等主线能力，每个项目都带最小可运行代码与配置说明。它是了解 Claude 生态最新 API 形态最快的方式，也是把 Claude 接入既有后端时最省事的模板来源。

**GitHub链接**：https://github.com/anthropics/claude-quickstarts

### 9. [lobehub/lobehub](https://github.com/lobehub/lobehub)
开源的超级 Agent 协作平台，核心理念是把"能自主干活、并且持续变强的 Agent"直接装进团队已经在用的聊天工具里，而不是让团队再多开一个系统。它支持多模型接入、Agent 群组编排、插件与工具扩展，并允许 Agent 主动认领任务、汇报进展。作为自托管选项，它在数据敏感度高的团队中替代闭源 SaaS 的吸引力明显，是本周榜单中体量最大的 Agent 平台型项目。

**GitHub链接**：https://github.com/lobehub/lobehub

### 10. [ZhuLinsen/daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis)
一个由 LLM 驱动的多市场股票智能分析系统，打通多源行情数据、实时新闻与决策看板，并支持零成本定时运行与自动推送。它把"取数—分析—结论—推送"整条链路做成可复用的工程模板：定时任务负责数据与结论生成，推送渠道负责触达。其价值不止于股票场景，更在于提供了一个通用的"LLM + 定时任务 + 自动推送"落地范式，中文文档齐全，上手成本低。

**GitHub链接**：https://github.com/ZhuLinsen/daily_stock_analysis

## 趋势洞察

**Skills 生态正式成为主战场。** 本周前十中有四个是纯 Skills 仓库，且占据 Stars 前三席中的两席——anthropics/skills、mattpocock/skills、addyosmani/agent-skills、cloudflare/security-audit-skill 合计吸走近万新增星标。竞争焦点已经从"谁的模型更强"彻底转向"谁能把工程方法论沉淀成 Agent 可执行的技能"，Skill 正在成为事实上的新型依赖包。

**标准化与生态位分层明显。** 官方仓库（Anthropic）定标准，个人专家仓库（Matt Pocock、Addy Osmani）供实战范本，企业官方仓库（Cloudflare）输出垂直领域技能——三层结构清晰可见。第三方作者若想被 Claude Code 生态直接复用，遵循官方目录约定几乎是必经之路。

**Agent 的手（Browser / Desktop / Computer Use）持续补齐。** vercel-labs 同周两个项目（agent-browser 与 agent-desktop）同时进入前十，且都在 Rust 上重写，目标是更低延迟、更省内存的 Agent 交互层。工具层正在从"能演示"走向"能扛生产流量"。

**语义层与确定性成为新叙事。** NVIDIA/auto-ontology 代表另一条路线：不再靠模型自由发挥查询，而是用本体与图谱把推理约束成确定性过程，用结构化换掉幻觉。这与 Skills 强调的"标准化流程"是同一个趋势的两面——都在把 Agent 从概率性黑盒拉回可预期轨道。

**AI 正快速渗透进垂直业务应用。** daily_stock_analysis 用 LLM + 定时任务 + 自动推送跑通了完整的投研流水线，与之前的聊天套壳不同，它有真实的数据源、调度与分发闭环。这类"可长期运行、有明确产出"的应用正在取代一次性 demo 成为新的项目形态。
