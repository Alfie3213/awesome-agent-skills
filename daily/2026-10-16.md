## 详细介绍

### 1. [obra/superpowers](https://github.com/obra/superpowers)

Superpowers 是一个 Agentic 技能框架与软件工程方法论项目，旨在让 AI Agent 具备真正的系统性开发能力。它不仅仅是一个工具库，更是一套完整的 Agent 开发范式，强调技能分解、上下文管理和任务规划。不同于传统的单 Agent 工具，Superpowers 鼓励将复杂任务拆解为可组合的技能单元，通过层次化的技能体系实现可靠的软件工程输出。GitHub Stars 已突破 29 万，是当前最具影响力的 Agent 工程化实践之一。

**GitHub 链接**：https://github.com/obra/superpowers

### 2. [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)

Hermes Agent 是 NousResearch 团队推出的渐进式成长型 AI Agent 框架，核心理念是让 AI Agent 能够像人类一样在多轮交互中持续学习和适应。与传统静态 Agent 不同，Hermes 具备动态知识更新能力，能够从对话历史中提取模式、修正错误并积累经验。项目采用模块化架构，支持多种底层 LLM，包括 Claude、GPT 系列和开源模型，为开发者提供了灵活的定制空间，是当前成长型 Agent 领域的标杆项目。

**GitHub 链接**：https://github.com/NousResearch/hermes-agent

### 3. [openclaw/openclaw](https://github.com/openclaw/openclaw)

OpenClaw 是一个通用 AI 助手框架，主打"真正做事情"的理念，支持在任意操作系统和平台上运行。它提供了完整的工具调用体系、任务编排能力和记忆管理机制，让 AI Agent 不仅能回答问题，更能实际执行文件系统操作、浏览器自动化、代码执行等真实任务。OpenClaw 的设计哲学强调可控性和可观测性，每个 Agent 操作都有清晰的日志和审计轨迹，适合需要深度 AI 集成的生产环境。

**GitHub 链接**：https://github.com/openclaw/openclaw

**GitHub 链接**：https://github.com/anthropics/skills

### 6. [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)

Firecrawl 是专为 AI Agent 设计的大规模网络数据采集引擎，能够将任意网站转化为结构化的 AI 可用数据。它不仅处理静态页面，还能执行 JavaScript 渲染、处理 SPA 应用、绕过反爬机制，并输出干净的 Markdown 或结构化数据。Firecrawl 提供了完善的 API 和 SDK，支持批量采集、去重、质量过滤等功能，是构建 RAG 系统、训练数据集或为 Agent 提供实时网络知识的关键基础设施。

### 7. [ollama/ollama](https://github.com/ollama/ollama)

Ollama 是最受欢迎的本地大模型运行平台，让开发者能够零配置地在本地运行包括 Qwen、DeepSeek、GLM、MiniMax、Gemma、Llama 在内的数十种开源大语言模型。它提供了统一的 API 接口，本地模型和云端模型可以无缝切换，极大降低了本地 AI 开发的门槛。Ollama 还支持模型的量化、微调和自定义导入，是个人开发者和中小企业构建私有 AI 能力的重要工具。

**GitHub 链接**：https://github.com/ollama/ollama

## 趋势洞察

**Skills 生态持续爆发**：本周 obra/superpowers、mattpocock/skills、Karpathy-skills、Ponytail 等技能框架继续领跑，Skills 正在成为 AI 时代的核心差异化要素。不同于传统的代码库，Skills 更像是一种"组织知识的方式"，让 AI Agent 能够调用特定领域的专家经验。预计 Skills 市场将在 2026 年底形成规模化的交易生态。

**Agent 框架格局初定**：OpenClaw、LangChain、NousResearch/hermes-agent 三足鼎立的格局正在形成。OpenClaw 以通用性和跨平台能力见长，LangChain 以生态完整性著称，Hermes-agent 则聚焦于 Agent 的自我进化能力。开发者选择框架时正在从"功能对比"转向"场景匹配"。

**数据基础设施不可或缺**：Firecrawl 和 Ollama 的持续高增长揭示了一个核心趋势——AI Agent 的能力边界往往不在模型本身，而在数据获取和本地推理能力。Firecrawl 解决"知道什么"的问题，Ollama 解决"本地能跑"的问题，两者共同构成了 Agent 部署的黄金搭档。

**本周总体态势**：AI/Agent 领域从"模型军备竞赛"转向"工程化深耕"阶段，Skills、框架、数据三大基础设施同步进化。2026年第四季度，Agent 正在从"能干活"向"干得好"的关键转型期。
